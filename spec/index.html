결과 화면(SCR-03~07)은 상단 탭으로 자유롭게 오가며, 코칭 화면에서 고친 코드를 다시 분석하면 처음 화면으로 돌아가 새 결과와 비교합니다.

SCR-01 코드 제출

화면 IDSCR-01메뉴 경로새 분석
화면 목적분석할 코드와 요구사항 문서를 올리고, 받고 싶은 분석 항목과 깊이를 골라 분석을 시작한다.
진입 경로상단 메뉴 "새 분석", SCR-07 "고친 코드로 다시 분석"이동 화면SCR-02 분석 진행

Description

No요소유형기능 설명
1입력 방식 선택탭코드 붙여넣기, 파일 업로드(zip·폴더), GitHub 저장소 주소 중 하나를 고른다.
2코드 입력 영역코드 편집기선택한 방식으로 올린 코드를 문법 강조와 함께 보여 준다. 붙여넣기 방식에서는 직접 편집할 수 있다.
3언어 · 요구사항 문서셀렉트 · 파일 첨부(선택)언어는 자동 감지 후 바꿀 수 있다. PRD 같은 요구사항 문서를 첨부하면 보완점 분석의 기준이 된다.
4분석 항목체크박스단위 테스트, 보완점, 대안 비교, 단점 분석, 개선 코드 제안 중 받을 항목을 고른다. 기본은 앞의 네 개.
5분석 깊이단일 선택빠르게·보통·꼼꼼하게. 깊을수록 검토하는 대안과 테스트 수가 늘고 시간이 길어진다.
6분석 시작버튼(주요)코드가 비어 있으면 비활성. 누르면 SCR-02로 이동한다. 아래에 코드 보관 기간 안내를 표시한다.

처리 규칙

  • 파일은 최대 50개, 합계 5MB까지 받는다.
  • 비밀 키 패턴(API 키, 토큰)이 보이면 분석 전에 가림 처리를 권하는 경고를 띄운다.

화면 IDSCR-02메뉴 경로새 분석 > 진행
화면 목적다섯 가지 분석이 어디까지 진행됐는지와 실시간 로그를 보여 주어 기다리는 동안 상황을 알 수 있게 한다.
진입 경로SCR-01 분석 시작이동 화면SCR-03 결과 요약(완료 시 자동 이동)

Description

No요소유형기능 설명
1전체 진행률진행 막대전체 진행률(%)과 분석 대상 파일 수, 언어를 보여 준다.
2단계 카드 5개상태 카드코드 이해 → 단위 테스트 → 보완점 → 대안 비교 → 단점 분석. 각 카드는 대기·진행 중·완료·실패 상태와 한 줄 요약을 보여 준다. 보완점·대안 비교는 동시에 진행된다.
3실시간 로그로그 목록테스트 통과 수, 실패 항목, 검토 중인 라이브러리처럼 사람이 읽을 수 있는 진행 기록을 시간순으로 보여 준다.
4취소 · 완료 알림버튼분석 취소(확인 창 후 중단), 완료되면 브라우저·메일 알림 받기.

처리 규칙

  • 한 단계가 실패해도 나머지 단계는 계속하고, 결과 화면에 빠진 항목을 표시한다.

진입 경로SCR-02 완료, 분석 기록 목록이동 화면SCR-04~07(탭), PDF 보고서

Description

No요소유형기능 설명
1결과 탭탭요약, 단위 테스트, 보완점·단점, 대안 비교, 코칭 화면을 오간다.
2핵심 지표 4개지표 카드종합 점수(100점), 테스트 통과(통과/전체), 보완점 수, 심각한 단점(high) 수. 카드를 누르면 해당 탭으로 이동한다.
3먼저 고칠 3가지표안전·보안 high → 테스트 실패 → 핵심 보완점 순으로 고른 세 항목. 행을 누르면 상세로 이동한다.
4영역별 점수막대 그래프정확성, 안정성, 보안, 유지보수성 점수.
5코칭 받으러 가기버튼(주요)SCR-07 코칭으로 이동한다.
6PDF 보고서 받기버튼요약과 모든 지적을 PDF로 내려받는다.

Description

No요소유형기능 설명

2실패 상세비교 패널선택한 실패 테스트의 기대값과 실제값을 나란히, 테스트 코드와 함께 보여 준다.
3원인 판정배지코드 결함 / 테스트 결함 / 환경 문제 중 하나와 판단 근거. 코드 결함만 개선 목록 후보가 된다.
4고치는 방법 · 재실행 · 내려받기버튼고치는 방법 보기(SCR-07로 이동), 테스트 다시 실행, 테스트 코드 내려받기(내 프로젝트에 넣어 쓰기).

Description

No요소유형기능 설명
1분류 · 심각도 필터칩 + 셀렉트전체, 보완점(요구사항 대비 빠진 것), 단점(있는 코드의 약점)으로 나누고 high·medium·low로 거른다.
2지적 목록표심각도, 분류, 한 줄 내용, 파일:줄 위치. 보완점 중 코드가 없는 것은 "해당 코드 없음"으로 표시한다.

4개선 목록에 담기 · 이의 제기버튼개선 목록(SCR-07)에 추가하거나, 지적이 틀렸다고 표시해 다음 분석에 반영한다.

4코치의 권고강조 패널교체 / 부분 도입 / 유지 중 하나와 한 문장 이유.

Description

No요소유형기능 설명
1나의 개선 목록체크리스트담은 항목과 추천 항목을 우선순위대로 보여 준다. 체크하면 반영 완료로 바뀌고 진행률이 오른다.
2AI 코치 대화채팅선택한 항목을 맥락으로 질문에 답하고, 넣을 위치와 코드 조각을 함께 보여 준다.
3추천 질문칩"왜 문제인가요?", "테스트도 보여 주세요", "다른 방법은?" 같은 질문을 한 번에 보낸다.
4고친 코드로 다시 분석버튼(주요)SCR-01로 이동해 이전 분석과 비교한 결과를 만든다.
