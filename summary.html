CodeCoach
코드를 올리면 AI가 코칭해 주는 웹페이지

개발자가 코드를 올리면 단위 테스트, 보완점, 다른 코드와의 비교, 현재 코드의 단점을 분석하고 고치는 방법까지 코칭해 주는 웹페이지

인태 · 핑거 교육 실습 · 2026-10-23

한눈에 보는 핵심 기능

개발자가 자기 코드에 대해 궁금한 네 가지 질문에 답합니다
1제대로 돌아가나요? → 단위 테스트
AI가 요구사항마다 테스트를 직접 만들어 실행하고, 실패하면 코드 문제인지 테스트 문제인지 알려 줍니다.
2무엇을 더 해야 하나요? → 보완점
요구사항 문서와 코드를 하나씩 대조해 빠졌거나 덜 만든 기능을 찾아 줍니다.
3다른 코드를 쓰면 뭐가 좋나요? → 대안 비교
지금 쓴 방법과 다른 라이브러리·방식을 기능, 비용, 실험 결과로 나란히 비교하고 바꿀지 권합니다.
4지금 코드의 약점은? → 단점 분석
버그 가능성, 안전·보안 문제, 고치기 어려운 구조를 파일·줄 위치와 실패 상황으로 보여 줍니다.

1코드 올리기
붙여넣기, 파일, GitHub 중 하나로 코드를 올리고 분석 항목을 고른다
2분석 지켜보기
5단계 진행 상황과 실시간 로그를 본다
3결과 요약 보기
점수와 먼저 고칠 3가지를 확인한다
4자세히 보기

SCR-01 코드 제출

1입력 방식 선택
붙여넣기·파일·GitHub 중 편한 방법 선택
2코드 입력 영역
올린 코드를 확인하고 바로 고칠 수 있음
3언어 · 요구사항 문서
요구사항 문서를 붙이면 빠진 기능까지 찾아 줌
4분석 항목
받고 싶은 분석만 골라 시간 절약
5분석 깊이
빠르게 볼지 꼼꼼히 볼지 선택
6분석 시작
누르면 바로 분석 시작
